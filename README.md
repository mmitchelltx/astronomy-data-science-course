# Astronomy Data Science With Python Programming Course - Udemy

## What I have learned:
* Python Programming: Master Python basics, including data types, variables, loops, conditional statements, and libraries like NumPy and Matplotlib.
* Image Processing: Learn how to process digital images using Python, including convolution operations, edge detection, and filters.
* Machine Learning: Gain a strong understanding of core ML concepts, including Linear and Logistic Regression, with practical coding examples.
* Deep Learning and CNNs: Build neural networks from scratch, train them using TensorFlow and Keras, and explore convolutional neural networks (CNNs).

## Hands-on Projects:
* Analyzing real astronomical image datasets like NGC3184 and M87.
* Building and training machine learning models for classification and regression tasks.
* Implementing neural networks and CNNs to solve real-world problems using Kaggle datasets.
